# Project Overview

> **Tayari.ai** is a production-grade AI Interview Platform that simulates real technical interviews using conversational AI, real-time voice, coding environments, and structured evaluation. The platform is designed to replicate the experience of interviewing with a human engineer while demonstrating production-level software architecture, AI orchestration, and scalable backend engineering.

---

# Vision

Build an AI interviewer that behaves like a skilled technical interviewer—not a scripted chatbot.

Unlike traditional interview preparation platforms that ask predefined questions, Tayari.ai conducts adaptive interviews by understanding the candidate's resume, job description, previous answers, coding performance, and overall interview context.

The long-term goal is to become a complete AI-powered technical interviewing platform for both candidates and organizations.

# Core User Flow

## Candidate Journey

1. Register or sign in.
2. Access the dashboard.
3. Create a new interview.
4. Configure interview settings.
5. Upload resume (optional).
6. Upload job description (optional).
7. Complete device checks.
8. Join the interview session.
9. Interact with the AI interviewer using voice and/or text.
10. Solve coding problems (if applicable).
11. Complete the interview.
12. AI evaluates the interview.
13. Review detailed reports and analytics.
14. Track progress over time.
